# Security

## Reporting a security problem

Write to security@meshsat.net, or use GitHub's private vulnerability reporting on this repository. Please do not open a public issue for it.

We confirm that we received it, fix what is ours to fix, and tell you what we did. There is no bounty.

The full policy is at https://meshsat.net/security/. The machine-readable contact is https://meshsat.net/.well-known/security.txt.

## What the Bridge keeps, and for how long

[docs/privacy-baseline.md](docs/privacy-baseline.md) lists every table the Bridge keeps, which ones can hold personal data, how long they are kept, and how the code is checked for leaked secrets and known vulnerabilities on every build.
