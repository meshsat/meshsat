# Field-kit hardware

The field-kit hardware moved to its own repository on 3 September 2026: **meshsat-fieldkit** (GitLab `products/meshsat/meshsat-fieldkit`).

- `v1/`: the tesseract and parallax kits as built (BOM, GPIO pinouts, Direwolf/AIOC notes, FreeCAD plate model).
- `v2/`: the Peli 1520 carrier PCB set (KiCad sources, generators, vendor references, Rev A release and order record, assembly and panel documents).

The kit provisioning scripts stay here (`scripts/install-kiosk.sh`, `scripts/install-kit-network.sh`, `scripts/x1202-monitor.py`, `deploy/kiosk/`).
